# 智景 ScenicMind 数据看板视觉设计稿

## 1. 设计目标

为“智景 ScenicMind”生成一张桌面端景区数据看板效果图。画面应像一款真实、成熟、可信的景区运营产品，而不是宣传海报或传统监控大屏。

整个页面只表达“以景区整体为单位”的客流数据，不出现景点点位、游客密度热力图、摄像头画面、地图定位或实时人员追踪。

核心视觉顺序：

1. 今日已入园人数
2. 今日预计总人数
3. 实际客流与预测客流趋势
4. Agent 数据报告
5. 未来客流与运营准备摘要

## 2. 视觉气质

- 关键词：松林、自然、安静、可靠、专业、克制、清晰。
- 主色使用深松绿色，避免鲜艳荧光绿。
- 页面整体为浅色模式，深绿色只用于侧边栏、重点数字、图表主线和少量按钮。
- 视觉感受接近高质量企业数据工具：信息紧凑但不拥挤，线条细，卡片克制，不使用厚重阴影。
- 不做科技蓝大屏，不做赛博风，不做玻璃拟态，不做夸张渐变。
- 可在深绿色侧边栏中加入极淡的山脊线或等高线纹理，透明度低于 6%，只增加景区气质，不抢信息。

## 3. 画布与布局

- 画布尺寸：1440 × 810 px（16:9），桌面端网页界面，正面平视。
- 左侧固定侧边栏：208 px 宽。
- 右侧主内容区：浅灰绿色背景，左右内边距 40 px，上下内边距 28 px。
- 主内容使用 12 列栅格，卡片间距 16 px。
- 页面圆角统一为 12 px；小按钮和标签使用 8 px，不使用大量胶囊形状。
- 卡片采用白色或极浅绿色背景、1 px 浅绿色边框、非常轻的阴影。

## 4. 色彩系统

### 主色

- 深松绿：`#123C2C`，用于侧边栏、主标题、实际客流线、主要按钮。
- 松绿：`#1F5A43`，用于重点数字、图标和选中状态。
- 青松绿：`#4F8068`，用于辅助强调、次级标签。
- 鼠尾草绿：`#91AE9B`，用于预测客流虚线、辅助图形。
- 淡松雾绿：`#E8F0EA`，用于选中标签、浅色提示和图表范围。

### 中性色

- 页面背景：`#F3F6F2`。
- 卡片背景：`#FFFFFF`。
- 暖白背景：`#FAFBF8`。
- 主要文字：`#17231D`。
- 次要文字：`#68766E`。
- 弱提示文字：`#96A29B`。
- 边框与分割线：`#DDE5DF`。

### 状态色

- 正常：`#3F7D5A`。
- 提醒：`#C58A32`，只少量用于客流较高提示。
- 风险：`#B65345`，只用于真正需要注意的状态。

状态不能只依赖颜色，同时配合“正常、较高、风险”等文字。

## 5. 字体与数字

- 中文字体：`Noto Sans SC`、思源黑体或苹方。
- 英文与数字：`Inter`。
- 页面标题：28 px，600 字重。
- 卡片标题：14 px，500 字重。
- 普通正文：13–14 px，400 字重。
- 辅助文字：12 px，400 字重。
- 两个核心人数：40–44 px，650 字重，使用等宽数字，让数字排列稳定。
- 图表坐标与数据标签：11–12 px，保持克制。
- 不使用书法字体、装饰字体或过度粗黑字体。

## 6. 页面结构

### 6.1 左侧导航

侧边栏为纯深松绿色 `#123C2C`。

顶部放置简洁文字品牌：

```text
智景
SCENICMIND
```

“智景”稍大，“SCENICMIND”使用 10 px 英文大写和较宽字距。

导航项目：

- 数据看板，当前选中
- 客流预测
- Agent 报告
- 运营准备
- 历史记录

选中项使用半透明浅绿色矩形背景和左侧 3 px 淡绿竖线。导航图标使用简单线性图标，不要彩色插画。

侧边栏底部显示：

```text
示范景区 · 全园
数据更新于 14:00
```

用一个小绿点表达数据正常，但不要写“实时”。

### 6.2 页面顶部

主内容顶部左侧：

```text
数据看板
2026年8月28日 · 星期五
```

右侧放置景区选择框“示范景区 · 全园”、通知图标和圆形用户头像。顶部保持轻量，不使用大面积横条。

### 6.3 两个核心数字卡片

页面第一行只放两张同等宽度的大卡片，二者必须是首屏最醒目的内容。

#### 卡片一：今日已入园人数

- 标题：今日已入园人数
- 主数字：`8,426`
- 单位：人
- 辅助文字：`截至 14:00`
- 右下角小字：`较上周同期 +8.4%`
- 卡片顶部可有极细的深松绿短线或简洁入园图标。

#### 卡片二：今日预计总人数

- 标题：今日预计总人数
- 主数字：`12,800`
- 单位：人
- 辅助文字：`预计范围 11,900–13,700`
- 右下角状态：`客流较高`
- 卡片使用非常浅的松绿色底 `#F7FAF7`，与第一张卡片轻微区分，但保持同等视觉重量。

卡片内不要放仪表盘、圆环图或复杂小图，保持数字清晰。

### 6.4 客流趋势主图

第二行左侧占 8 列，右侧 Agent 报告占 4 列，二者高度一致，约 380 px。

趋势图卡片标题：`客流趋势`。

标题右侧放置时间切换：

```text
日  周  月
```

“日”为当前选中状态，使用淡松雾绿色背景。若生成效果图，日视图展示 08:00–18:00 的全园小时客流。

图表要求：

- 实际客流：深松绿色实线，线宽 2.5 px。
- 预测客流：鼠尾草绿色虚线，线宽 2 px。
- 预测可能范围：极淡半透明绿色面积带。
- 当前时间 14:00：一条细竖线和小标签“当前”。
- 实际线到 14:00 结束，预测线继续延伸到闭园时间。
- 横轴为时间，纵轴为“入园人数”，不出现小数。
- 背景网格只保留浅色横线，不保留密集竖线。
- 图例：`实际客流`、`预测客流`、`预计范围`。
- 最高峰附近标注：`预计峰值 1,420人 / 15:00`。

曲线应自然平滑但不过度圆润；禁止使用柱状图作为主视觉。

### 6.5 Agent 数据报告

右侧卡片标题：`Agent 数据报告`，标题旁放一个小型松针或星点图标，避免机器人头像。

卡片顶部放浅绿色标签：`今日简报`。

正文分成三段，每段前使用小号序号或细线图标：

```text
发生了什么
今日客流预计较上周同期增长 11%。

可能的原因
周末临近、天气晴朗，预约量从上午开始明显上升。

运营提示
15:00 前后可能出现今日客流高峰，建议提前确认高峰接待预案。
```

底部使用很轻的分割线，放置：

```text
分析把握：中等    查看完整报告 →
```

整张卡片保持留白，不放聊天气泡，不设计成即时通讯窗口，不使用大段密集文字。

### 6.6 底部区域

第三行左侧为“未来 7 天”，右侧栏底部为“运营准备”。在 810 px 高的 16:9 效果图中完整露出，底部与画布保留约 24 px 安全间距。

#### 未来 7 天

使用简洁横向列表或微型折线，不做七张重复小卡片。

示例内容：

- 周六 12,800人，较高
- 周日 9,600人，正常
- 周一 6,300人，正常
- 周二 5,900人，正常
- 周三 7,200人，正常
- 周四 8,100人，正常
- 周五 10,400人，提醒

天气只用简单线性图标和文字，不使用彩色卡通图标。

#### 运营准备

这一区域不是实时调度台，不出现地图和人员位置。视觉上呈现为简洁的预案摘要：

```text
周六 · 客流较高
建议检查高峰接待预案

开放入口     当前 3    建议 4
摆渡车辆     当前 6    建议 8
现场人员     当前 42   建议 48
```

底部放一个深松绿色按钮：`查看运营准备`。

所有建议数字只是视觉示例，卡片旁用小字注明“以景区预案设置为准”。不要表现为系统自动下达命令。

## 7. 卡片与细节

- 卡片边框：1 px `#DDE5DF`。
- 卡片圆角：12 px。
- 卡片内边距：20–24 px。
- 阴影：`0 4px 18px rgba(18, 60, 44, 0.05)`，只能轻微出现。
- 卡片标题和内容之间保持 16–20 px 间距。
- 小图标统一使用 1.5 px 线宽的单色线性风格。
- 主按钮高 38–40 px，8 px 圆角，不使用超大胶囊按钮。
- 数字、坐标和列表对齐要严谨，体现数据产品感。

## 8. 信息层级

第一眼必须先看到两个数字：`8,426` 与 `12,800`。

第二眼看到实际线与预测线的走势，以及下午峰值。

第三眼看到 Agent 的三段式结论。

未来 7 天和运营准备属于补充信息，视觉重量必须低于趋势图。

## 10. 视觉边界

- 页面表达的是景区整体客流，不表达景区内部某个位置的人流密度。
- “今日已入园人数”必须带明确的数据更新时间。
- “今日预计总人数”必须与已入园人数视觉并列，不能藏在图表里。
- Agent 报告是结构化运营摘要，不是聊天机器人。
- 运营准备是预案建议，不是实时自动调度。
- 页面不承诺当前数据能力之外的视觉功能。
